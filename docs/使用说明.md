# 云海仙宗

## 文件
- `云海仙宗.blend`：可编辑三维场景，使用 Blender 5.2.3 LTS 创建。
- `云海仙宗-全景.png`：主摄影机的 16:9 全景渲染。
- `云海仙宗-主殿近景.png`：主殿建筑与前庭的细节渲染。
- `scene-inventory.json`：对象、网格、材质、摄影机和渲染设置清单。

## 打开和编辑
直接在 Blender 中打开 `.blend`。活动场景为「云海仙宗 | CLOUD SEA SANCTUARY」。工程里的模型、曲线、材质节点、灯光、体积云和摄影机均可编辑；查看或重新渲染不需要安装 MCP 插件，也不依赖外部贴图。

场景按六个集合组织：
1. 九重群山：承载建筑的山峰、远山、侧峰和断岩。
2. 宗门建筑：主殿、藏经阁、长老殿、弟子院落、山门与亭阁。
3. 石阶与廊桥：跨谷拱桥、御阶、台基护栏与山路。
4. 松竹灵泉：松树、竹林、瀑布、水潭、石灯、香炉、石狮、仙鹤及旗幡。
5. 云海与大气：非均匀体积云与大气透视。
6. 摄影机与光照：全景、主殿细节、山门三台摄影机及灯光。

## 摄影机
- `01 · 云海仙宗 / Establishing`：35mm，默认全景。
- `02 · 天阙主殿 / Architectural detail`：45mm，主殿近景。
- `03 · 入山问道 / Gate`：32mm，山门视角。

选中摄影机后可通过「视图 → 摄影机 → 将活动物体设为活动摄影机」切换。数字键盘 0 进入当前摄影机，F12 重新渲染。体积云在实体视图中可能显示为包围几何体，需在渲染视图或最终渲染中查看云雾。

## 建模和渲染
屋顶由四坡曲面、瓦垄、檐口、屋脊和鸱吻几何组成；柱础、朱柱、斗拱、窗棂及栏杆按模块建模。单个建筑内同类构件合并为网格，进入编辑模式仍可分别选取不相连的构件。装饰雕塑采用简化几何造型。

地形为程序化网格，云海为三维体积材质。正式渲染设置为 Cycles、1920×1080、64 采样、降噪。当前电脑使用 Metal GPU；换到其他电脑后可在 Cycles 设置中选择其可用渲染设备。

场景通过 `mcp-for-blender 2.2.4` 的 `execute_blender_code` 在本机 Blender 中实际创建。MCP 连接组件在本次 Blender 会话加载，未修改 Codex 的全局 MCP 配置。
