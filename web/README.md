# 云海仙宗 · 山海漫游

现有 Blender 场景转换的 Three.js 网页漫游。原始 `.blend` 不变。

在线体验：[云海仙宗 · 山海漫游](https://yunhai-sect.vercel.app/)（Vercel）。

## 启动

```sh
npm ci
npm run dev
```

开发预览默认 http://127.0.0.1:4318/ 。发布：`npm run build`，静态目录 `dist/`。需要通过 HTTP 服务访问，不支持直接双击 HTML。

## 操作

- 环绕：拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放。
- 步行：先点击“步行探索”，再点击画面。WASD / 方向键移动、Shift 加速、Esc 释放鼠标；不支持鼠标锁定时按住画面拖动转头。
- 手机：左侧摇杆移动，右侧拖动转头。
- 六个观景点可切换地点，返回全景可恢复初始视角。
- 画质和云雾可随时切换。

## 模型与碰撞

`public/assets/sanctuary.glb` 为实际 Blender 场景导出的 Draco 压缩 glTF，约 2.95 MB、64 万三角面、14 组合并网格（多材质组可产生多个绘制调用）。离线程序化材质转换为实时 PBR 材质；体积云替换为轻量雾片和距离雾。与 Cycles 渲染的表现有所不同。

步行采用加速网格射线检测，包含头部/肩部障碍检测、台阶高度限制和边缘防跌落。它是观景漫游控制器，不包含跳跃、攀爬或室内穿门功能。原模型的殿身为实心几何，室内不可进入。

`npm test` 验证地面行走、墙体阻挡、悬崖保护和台阶攀爬。桌面与窄屏布局、模式切换、观景点及真实移动另经浏览器检查。

## 技术

Three.js / three-mesh-bvh / Vite。已部署至 Vercel。完整可编辑源场景位于 `../blender/云海仙宗.blend`。
